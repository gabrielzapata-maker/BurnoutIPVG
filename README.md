
# Mental Health Burnout · Facultad de Psicología UdeC

Plataforma web de concientización y autoevaluación sobre el Síndrome de Burnout en el ámbito académico, desarrollada para la Facultad de Psicología de la Universidad de Concepción.

# Alcance de la Primera Entrega:

    Estructura base del sitio y navegabilidad funcional para todas las secciones del mapa del sitio:

Inicio: Presentación general del proyecto.

¿Qué es?: Información sobre el burnout vs. estrés.

Manual de cuidado: Consejos de prevención.

Sobre el proyecto: Contexto y objetivos.

Autotest: Sección base para la evaluación orientativa.

# Tecnologías Utilizadas

HTML: Estructura semántica del sitio y componentes navegables. 

CSS: Diseños responsivos y estilos visuales base.

JavaScript: Navegación dinámica entre secciones y control del menú móvil.
